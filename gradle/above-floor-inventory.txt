# Every class in the published jar allowed above Java 8, and the Java version it needs.
#
# Pinned as an explicit inventory rather than a package prefix. The prefix this replaced,
# "com/kamikazejam/kamicommon/nms/", exempted 1401 classes so that 160 could be above the
# floor. The other 1241 include the always-loaded dispatch layer, nms/abstraction and
# nms/provider, which a 1.8.8 server loads unconditionally. A spigot-nms release raising one
# of those above Java 8 would have passed this check and died on the server.
#
# A name rule cannot replace it either: the version markers are irregular. Teleporter1_21_9,
# Teleporter1_20_CB, WorldGuard7 and ModernVersionedComponent all belong here and share no
# pattern with _LATEST or _1_17_R1.
#
# So the set is pinned. A class above Java 8 that is NOT listed fails the build, and a listed
# class that has disappeared fails it too, so this file cannot rot into a blanket exemption.
# Regenerate deliberately when spigot-nms moves, and read the diff: a new entry under
# nms/abstraction or nms/provider is a real regression, not a rename.
#
